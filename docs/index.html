A simple tool that watches websites for you.

Service Pulse checks a list of websites on a schedule, notes whether each one is up, and sends an alert the moment something goes wrong.

Built and maintained byPrasad Bhor

What it does

The idea: every five minutes, a small program visits each website on a list and asks a simple question — are you working? It notes whether the site responded properly and how long it took.

If a website stops responding properly, an email goes out straight away — so nobody has to sit and watch a screen waiting for something to break. There's also an optional step where a failing check can automatically create a support ticket in Salesforce, so the issue gets tracked without anyone lifting a finger.

What's under the hood

the concepts this project is built on

AzureHosts the cloud resources — storage, logging, and the alerting rule that watches for failures.
TerraformDescribes the entire Azure setup in code, so it's built the same way every time instead of by hand.
PythonDoes the actual work — visiting each site, timing the response, and deciding pass or fail.
GitHub ActionsTests the code, deploys the infrastructure, and runs the checks themselves on a schedule.
Application InsightsKeeps a record of every check, so nothing is lost once the moment passes.
